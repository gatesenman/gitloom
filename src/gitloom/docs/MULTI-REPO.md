# GitLoom v0.3 · 多仓库项目（嵌套 / 子模块 / 工作树）交互设计

## 1. 发现（Discovery）
- `src/main/git/discovery.ts`：纯 Node、可单测。广度优先遍历，8 路并发；默认深度 6（设置可调）；
  忽略列表支持名称与 `*` 通配（默认 node_modules、.venv、dist、target、build、out、vendor、.cache…）。
- 符号链接：跟随一次，按 realpath 去重 → 防循环、防同一仓库出现两次。
- 仓库类型：普通 / 嵌套（位于另一仓库工作区内）/ 子模块（.gitmodules 声明；未初始化的也列出；
  声明路径即使在忽略目录内也会被显式探测，如 `vendor/deep`）/ 工作树（gitfile → commondir 解析主仓库；
  项目外的工作树通过主仓库 `.git/worktrees/*/gitdir` 发现）/ 裸仓库（不向下遍历）。
- 父仓库关系：嵌套仓库标注父仓库如何看待该路径：已忽略 / 未跟踪 / gitlink（无 .gitmodules 的内嵌仓库）/ 跟踪了其中文件。
- 后台扫描：进度事件（文件夹数、已发现数、当前路径）+ 取消；扫描结果按根目录缓存原始命中，
  增量重扫仅替换子树后重新分类。
- 监视：对扫描过的目录（上限 1500 个）做非递归 fs.watch，900ms 防抖后只重扫变化的最浅目录；
  对各仓库 git 目录（index/HEAD/refs）监视，400ms 防抖后只刷新该仓库状态。

## 2. 侧边栏 = 项目树
- 项目切换器（多项目）、筛选框（模糊匹配名称/路径/分支，高亮祖先链）、视图模式：树 / 列表 / 按状态分组。
- 树镜像真实目录，单子文件夹链压缩为 `a/b/c`（VS Code 风格）；仓库节点下可再挂嵌套仓库；项目外工作树挂在其主仓库下。
- 徽章自下而上汇总：改动文件数、↑领先 ↓落后、冲突、分离 HEAD（子模块天然分离，不计入）、脏子模块、不可用。
- 已固定（可拖动排序）、最近；右键菜单：终端 / 文件管理器 / 编辑器、抓取 / 拉取 / 推送、固定、复制路径、重新扫描此文件夹、隐藏（可撤销）。
- 键盘：↑↓ PgUp/PgDn Home/End、→ 展开 / 进入、← 折叠 / 回到父级、Enter 打开、Space 切换、直接输入字母跳转（type-ahead）。
- 虚拟化渲染（固定行高，随密度 28/24px），200+ 仓库不卡顿。

## 3. 工作区概览（Dashboard）
- 范围 = 项目或任意文件夹节点；状态筛选卡片；表格 / 卡片两种布局；虚拟列表。
- 多选（Shift 连选）后批量：抓取、拉取（仅快进）、推送、切换分支、新建分支、储藏、运行 git 命令。
- 默认安全：无上游 / 分离 HEAD / 无改动 / 冲突的仓库跳过并说明原因；推送、切换、储藏、命令需确认；
  危险命令二次确认；命令不经 shell。
- 并发上限（设置，默认 6），逐仓库进度 + 结果日志（可调高度、仅看失败、取消剩余），完成后提供“撤销”（切回原分支 / stash pop）。

## 4. 跨仓库变更
- 所有有改动仓库的文件按仓库分组；乐观暂存 / 取消暂存；每个仓库独立的提交框与 AI 生成；
  “AI 全部生成”“提交 N 个仓库”；提交后 toast 可“撤销提交”（reset --soft HEAD~1）。

## 5. 导航
- 顶栏面包屑：项目 ▸ 文件夹… ▸ 仓库 ▸ 分支，每段都是快速切换器（项目列表 / 文件夹概览 / 同级仓库 / 分支列表），过深时中段折叠为“…”。
- Ctrl/⌘+P 快速打开仓库（跨项目、最近优先、模糊高亮）；Ctrl/⌘+K 命令面板（含全部新功能）；Tab 在两者间切换。
- Ctrl/⌘+0 概览、Ctrl/⌘+1..8 仓库视图、Ctrl/⌘+Shift+E 聚焦树、Ctrl/⌘+Shift+F 筛选、Ctrl/⌘+B 侧边栏。

## 6. 通用体验
- 视图从侧边栏移到主区标签栏（工作区标签 | 仓库标签），侧边栏专注于项目导航。
- 撤销 toast（隐藏仓库、批量切换 / 新建分支 / 储藏、提交）；所有长操作非阻塞并显示进度。
- 可记忆布局：侧边栏宽度、各分栏、结果面板高度、展开状态（按项目）、视图模式。
- 密度：舒适 / 紧凑（侧边栏底部一键切换）。
- 首次打开引导：选择文件夹 → 扫描（雷达动画 + 实时计数 + 取消）→ 项目树。
